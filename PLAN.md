# Thorough Chests plan

Name Thorough Chests, id `thoroughchests`, package `com.itmecasey.thoroughchests`, repo and wiki slug `thoroughchests`. MIT. Both sides.
One sentence: chests with big scrolling, searchable inventories, five levels from copper to netherite, upgrade cards, and augments that compact, smelt, attract, feed and void items.

## Targets
Forge and NeoForge on Minecraft 26.1.2, 26.2 and 26.3 (six modules plus shared `common/`), one combined jar per Minecraft version. Java 25.
Forge 64.1.6 / 65.1.6 / 66.1.5, NeoForge 26.1.2.125 / 26.2.0.93 / 26.3.0.101 (same pins as BarelyStorage). Version 2026.11.1.

## Layout (same as BarelyStorage)
- `common/` Minecraft-free logic, unit tests, shared resources (lang, textures, recipes, blockstates).
- `version-26.2/` master Minecraft code; `version-26.1.2` and `version-26.3` are generated by `scripts/sync_versions.py` (never edit the copies).
- `forge-<mc>/`, `neoforge-<mc>/` thin loader layers: registration, item-handler access, client setup, viewer plugins.
- `scripts/` build, combine, sync, textures (`make_textures.py`), server check, client tour, branding.
- `docs/DESIGN.md` is the spec; `docs/COMPLETION_REPORT.md` is written last.

## Dependencies
None required. Optional (soft, by reflection or plugin annotations): BEI (`bei-api`), JEI, REI, SMWTI, Jade, ModJS, KubeJS.
EMI has no build for 26.1.2, 26.2 or 26.3 (checked 2026-11-14) and is a known gap; its plugin is not written because nothing can compile against it.

## Art
Vanilla textures only. `scripts/make_textures.py` builds every chest texture from the vanilla chest texture (a frame taken from the level below), the block particle textures, the item icons (card, lock, augments) and the GUI sheet. Textures stay unapproved.
